# skills

Agent skills I use. One for now.

| Skill | What it does |
| --- | --- |
| [clean-docs](skills/clean-docs/SKILL.md) | Sweep a repo's markdown — delete every doc the code contradicts or already says, and cut what survives down to size. |

## Install

With [skills.sh](https://skills.sh):

```bash
npx skills add Anggel7x/skills
```

Or copy a skill folder into `~/.claude/skills/` (all projects) or `.claude/skills/` (one project).

## Use

In Claude Code, run `/clean-docs`. It only runs when you call it.
